### 🚀 Building now: Oncourt

A sports platform for Lebanon. Players find and book padel, football, basketball, tennis and volleyball courts, play matches with friends and pay at the club. Clubs run everything from their own dashboard.

- 📱 **Player app** (Flutter, Android & iOS): live availability on a map, matches with friends, player profiles
- 🏟️ **Venue dashboard**: bookings, phone/walk-in reservations, pricing, promotions, court management
- 🛡️ **Backend** (Supabase / PostgreSQL): row-level security, race-safe bookings, realtime updates
- ✅ **Quality**: 100+ automated tests incl. tests against a live backend, CI/CD with GitHub Actions
